# Dog API Explorer - Open API Project

This project is a technical demonstration of using the **Fetch API** and **Async/Await** to pull data from [TheDogAPI](https://thedogapi.com/) and render it into a responsive user interface. This project was built as a final assignment for the Code the Dream "Intro to Programming" course.

## Project Requirements Satisfied
- **Two Endpoints:** Data is fetched from both the `/images/search` and `/breeds` endpoints.
- **Separate GET Requests:** Navigation triggers unique fetch calls to retrieve only the data needed for the current view.
- **Responsive Design:** The layout uses CSS Grid and Flexbox to adapt to mobile, tablet, and desktop screens.
- **Error Handling:** Includes catch blocks to manage and display API or network errors to the user.

## Technologies Used
- HTML5
- CSS3 (Custom properties and Media Queries)
- JavaScript (ES6+, Fetch API, Promises)
